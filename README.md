# Académie Shinigami — Cours RP

Site statique consacré au Hakuda, au Zanjutsu et aux tactiques de combat, avec questionnaire interactif.

## Aperçu local

Ouvrez simplement `index.html` dans un navigateur, ou lancez un serveur statique dans ce dossier.

## Publication

Les fichiers peuvent être publiés gratuitement sur GitHub Pages, Netlify, Cloudflare Pages ou tout autre hébergeur statique. Aucun serveur ni base de données n'est nécessaire.
